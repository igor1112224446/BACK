# Сервис публикации объектов: MyHome, SS.ge, Korter

Ты добавляешь объект (параметры + фото) в веб-интерфейсе → сервис ставит на фото
логотип и телефон, ИИ пишет заголовок и описание на грузинском, русском и английском →
агент публикации открывает формы площадок в браузере и заполняет их.

Работает на твоём компьютере: публикация идёт из твоих аккаунтов на площадках,
а у них нет открытого API, поэтому агенту нужен браузер с твоими логинами.

## Установка (один раз)
```
pip install -r requirements.txt
python -m playwright install chromium
```
1. Положи логотип в `assets/logo.png` (PNG, прозрачный фон).
2. В `config.yaml` впиши телефон.
3. Ключ Claude API (для ИИ-текстов и разбора описания): получи на console.anthropic.com
   и задай переменную окружения. Windows: `setx ANTHROPIC_API_KEY "sk-ant-..."` и перезапусти терминал.
   Без ключа сервис работает, тексты будут по шаблону.

## Подключение площадки (для каждой: myhome, ssge, korter)
```
python worker.py login myhome     # войди в аккаунт, нажми Enter
```
Открой в своём кабинете форму «Добавить объявление», скопируй адрес в `config.yaml → platforms.myhome.add_url`.
```
python worker.py record myhome    # заполни форму руками тестовыми данными, НЕ публикуй
```
Скопируй код из окна Playwright Inspector и пришли его Claude — он переведёт его в список `fields`
в config.yaml (какое поле формы заполнять каким значением объекта).

## Ежедневная работа
Запусти два окна:
- `start_service.bat` — сервис, откроется http://localhost:8000
- `start_agent.bat` — агент публикации

В сервисе: «Добавить объект» → фото и параметры (или опиши объект одним сообщением и нажми «Разобрать текст»)
→ «Сохранить объект» → проверь текст → отметь площадки → «Опубликовать на отмеченных».

Режим `assist` (по умолчанию): агент заполняет форму, ты проверяешь её в браузере, жмёшь
«Опубликовать» на площадке и «Опубликовано» в сервисе. Когда площадка стабильно заполняется
без правок — поставь `publishing.mode: auto`.

## Заметки
- Korter в первую очередь работает с новостройками; для вторички от агентства может понадобиться
  агентский кабинет — уточни у их поддержки.
- Не публикуй десятки объектов подряд за минуты: пауза между публикациями задана в config.yaml.
- Удаление объекта в сервисе не снимает его с площадок.

## MyHome, SS.ge и Korter — через расширение Chrome
Эти площадки блокируют автоматизированный браузер, поэтому для них сделано расширение,
которое работает в твоём обычном Chrome.

Установка (один раз):
1. Открой в Chrome адрес `chrome://extensions`
2. Справа вверху включи «Режим разработчика»
3. Нажми «Загрузить распакованное расширение» и выбери папку `chrome-extension`
4. Закрепи значок расширения (пазл на панели → булавка у «Listing Hub»)

Публикация:
1. Запусти сервис (`start_service.bat`), добавь объект
2. В Chrome открой форму добавления объявления на MyHome, SS.ge или Korter (ты должен быть залогинен)
3. Нажми значок расширения → выбери объект → «Заполнить форму»
4. Дозаполни то, что отмечено ✗ (адрес), проверь и опубликуй
5. В расширении нажми «Отметить опубликованным» — в сервисе площадка станет зелёной

Если какие-то поля не заполняются: в расширении «Настройки и диагностика» → «Сканировать форму»
и пришли Claude файл `*-form-scan.json` из «Загрузок».

## Сохранить объявление со страницы одной кнопкой
Открой в Chrome любое объявление (MyHome, SS.ge, Korter, сайт агентства и т.д.), нажми значок
Listing Hub → «Сохранить объявление с этой страницы». Сервис заберёт параметры, текст и фото,
поставит на фото твой логотип и телефон и напишет новые тексты. Повторно одно и то же объявление
не сохраняется. Если фото не подтянулись — пролистай галерею объявления и нажми ещё раз.

## База объявлений (CRM) из выдачи MyHome
1. Открой на MyHome страницу со списком объявлений (например, продажа квартир в Сабуртало).
2. Нажми значок Listing Hub, выбери, сколько страниц собрать, и нажми «Собрать объявления в базу».
   Сбор идёт в фоне с паузами 5–9 секунд между страницами; окошко расширения можно закрыть, кнопка «Остановить сбор» — там же.
3. База открывается по адресу http://localhost:8000/crm (или кнопкой «База объявлений» в сервисе):
   фильтры по району, комнатам, цене, статусу, собственник/агентство; статус и заметка у каждого объявления;
   ссылка на оригинал; выгрузка в CSV. Повторный сбор обновляет цены и отмечает, если цена снизилась.

## Объявление с halooglasi.com → перевод на русский и пост для Threads
Открой объявление на halooglasi.com в Chrome, нажми значок Listing Hub →
«Перевести на русский и сделать пост для Threads». Расширение читает текст страницы, сервис
(через ИИ, нужен ANTHROPIC_API_KEY) переводит объявление на русский и пишет короткий пост до 500 символов.
Пост можно скопировать кнопкой; полный перевод — в разделе «Полный перевод на русский».

Телефон и Telegram в посте берутся из самого объявления, если они там есть. Не придумываются.
Эту кнопку можно использовать для объявлений любых сайтов, которые открыты в браузере.

Пост для Threads собирается по шаблону: меняются только район и площадь. Контакты по умолчанию —
WhatsApp, Telegram и канал; их можно переопределить в `config.yaml` в разделе `threads:`
(ключи `whatsapp`, `telegram`, `channel`). Пост сохраняется в объявление и при заполнении Threads уходит как есть.

Пост для Threads создаётся без ИИ и без расходов на токены: район, площадь и цена берутся из текста страницы
(регулярные выражения и словарь районов Белграда в `ai.py`, `DISTRICTS`). Если что-то не нашлось, расширение
покажет это предупреждением — поправь пост вручную. Полный перевод объявления в этом режиме не делается.
